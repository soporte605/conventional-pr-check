Conventional PR Check

La extensión muestra un panel en las páginas de pull request de GitHub cuando el título no sigue Conventional Commits, con un título sugerido.

Necesario para aplicar el título con un clic y para repositorios privados. Usa un token de acceso detallado (fine-grained) con permiso Pull requests: Read and write en los repositorios donde lo vayas a usar. El token se guarda solo en este navegador.
