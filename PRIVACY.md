# Política de privacidad / Privacy policy

_Última actualización / Last updated: 2026-11-03_

## Español

La extensión **Conventional PR Check** no recopila, vende ni comparte datos personales.

- **Token de GitHub:** si lo configuras en las opciones, se guarda solo en tu navegador (`chrome.storage.local`) y se envía únicamente a `api.github.com` para leer el pull request que estás viendo y, cuando pulsas **Aplicar título**, cambiar su título.
- **Datos del pull request:** la extensión lee el título, la descripción y las etiquetas del pull request abierto para validarlo. Se procesan en tu navegador y no se envían a ningún otro servidor.
- **Sin analítica ni seguimiento:** no hay telemetría, cookies propias ni servidores de terceros.

Puedes borrar el token en cualquier momento desde las opciones de la extensión o desinstalándola.

## English

The **Conventional PR Check** extension does not collect, sell or share personal data.

- **GitHub token:** if you set one in the options, it is stored only in your browser (`chrome.storage.local`) and sent only to `api.github.com` to read the pull request you are viewing and, when you click **Aplicar título** (Apply title), to change its title.
- **Pull request data:** the extension reads the title, description and labels of the open pull request to validate it. They are processed in your browser and are not sent to any other server.
- **No analytics or tracking:** there is no telemetry, no own cookies and no third-party servers.

You can remove the token at any time from the extension options or by uninstalling it.
